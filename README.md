# KIWI-GANG - KiwiExpress

Proyecto de la asignatura DSY1104 Desarrollo FullStack II de Duoc UC.

KiwiExpress es una empresa de transporte y distribucion de paquetes que opera en la Region
Metropolitana. Este sitio web permite que los clientes soliciten sus envios, revisen el estado
de sus paquetes con un codigo de seguimiento, y que los administradores gestionen los envios
y usuarios desde un panel aparte.

## Integrantes

- LiinooRF
- TomAlig
- ignmartinezt

## Tecnologias

- HTML5
- CSS (hoja de estilos propia en assets/css/estilos.css)
- JavaScript
- Bootstrap 5
- El deploy esta hecho en Dokploy

## Paginas del sitio

- index.html: pagina principal
- seguimiento.html: buscador de envios por codigo
- envio.html: formulario para solicitar un envio, guarda los paquetes en localStorage
- registro.html y login.html: registro e inicio de sesion con validaciones
- nosotros.html, blogs.html y contacto.html: paginas informativas
- admin.html, admin-usuarios.html y admin-envios.html: panel de administracion

## Como verlo

El sitio esta publicado en https://kiwi.169-58-170-142.sslip.io

Si lo quieres ver en tu computador solo tienes que clonar el repositorio y abrir el
index.html en el navegador, no necesita instalar nada.

Las tareas estan repartidas en los issues del repositorio y cada uno trabaja en su propia
